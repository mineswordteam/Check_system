# سیستم کنترل دسترسی

## فایل‌ها
- `config.json` — لیست شناسه‌های بلاک‌شده. برنامه‌ها این فایل را می‌خوانند.
- `guard.js` — این اسکریپت را در ابتدای هر برنامه (در `<head>` یا شروع `<body>`) لود کن.
- `admin/index.html` — پنل مدیریت برای دیدن و ویرایش لیست بلاک (بدون نیاز به باز کردن گیت‌هاب).
- `whoami.html` — صفحه‌ای که شناسه‌ی دستگاهِ بازکننده را نشان می‌دهد؛ برای شناسایی دستگاه یک نفر خاص.

## راه‌اندازی

1. این پوشه را در یک مخزن گیت‌هاب (پابلیک یا پرایوت) آپلود کن.
2. در `guard.js`، مقدار `CONFIG_URL` را با آدرس واقعی مخزنت جایگزین کن:
   ```
   https://cdn.jsdelivr.net/gh/USERNAME/REPO@main/config.json
   ```
3. فایل `guard.js` را در تک‌تک برنامه‌هایت اضافه کن:
   ```html
   <script src="guard.js"></script>
   ```
   (یا محتوایش را مستقیم کپی کن اگر همه چیز باید در یک فایل باشد.)
4. `admin/index.html` را در مرورگر خودت باز کن (لازم نیست هاست شود؛ می‌توانی مستقیم از روی دیسک باز کنی) و با یک GitHub Personal Access Token متصل شو. راهنمای ساخت توکن داخل خودِ صفحه هست.

## پیدا کردن شناسه‌ی یک دستگاه خاص

چون هیچ لاگینی در کار نیست، شناسه‌ها فقط UUID تصادفی هستند. برای اینکه بفهمی کدام شناسه مال کدام شخص است:

- ساده‌ترین راه: آدرس `whoami.html` را (بعد از آپلود در گیت‌هاب یا هرجای دیگر) برای طرف بفرست یا از گوشی‌اش باز کن؛ شناسه نمایش داده می‌شود و می‌توانی کپی‌اش کنی.
- یا وقتی خودت برنامه را روی گوشی‌اش نصب می‌کنی، از کنسول مرورگر (`window.__deviceInfo`) شناسه را بگیر.

## نکته‌ی مهم درباره‌ی رفتار برنامه

این سیستم فقط **وقتی کاربر خودش برنامه را باز می‌کند** چک انجام می‌دهد. هیچ اجرای پس‌زمینه یا ارسال خودکار بدون باز شدن برنامه در این طراحی وجود ندارد؛ این عمداً همین‌طور طراحی شده چون اجرای مخفی در پس‌زمینه هم خلاف سیاست‌های فروشگاه‌های اپ (از جمله مایکت) است و هم در اکثر پلتفرم‌ها دیگر عملاً ممکن نیست.

اگر کاربر بدون اینترنت باشد، چک رد می‌شود و برنامه به‌صورت عادی باز می‌شود (چون فایل کانفیگ قابل‌دسترس نیست). اگر بخواهی حالت «حداکثر N روز آفلاین مجاز» هم اضافه شود، بگو تا نسخه‌ی بعدی `guard.js` را با آن قابلیت بفرستم.
