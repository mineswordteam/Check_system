اتصال به مخزن گیت‌هاب

این پنل مستقیماً با API گیت‌هاب صحبت می‌کند؛ هیچ سرور واسطه‌ای وجود ندارد. توکن فقط در همین مرورگر و همین صفحه نگه‌داری می‌شود.

راهنمای ساخت توکن:
  1. در گیت‌هاب به Settings → Developer settings → Fine-grained tokens برو.
  2. یک توکن جدید بساز، فقط همین مخزن (Repository) را انتخاب کن.
  3. در بخش Permissions، دسترسی Contents را روی Read and write بگذار.
  4. توکن ساخته‌شده را همین‌جا وارد کن.
